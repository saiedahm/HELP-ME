# HELP ME

> Tell me what you need. I'll help you get it done.

HELP ME is an AI-powered task execution platform.

The user describes what they need.

HELP ME understands the request, plans the work, executes permitted operations,
verifies the result, requests confirmation when required, and records the
important operations for audit.
